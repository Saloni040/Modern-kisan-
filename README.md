## Problem
Kisan ko apni fasal ka 30-40% daam middleman kha jata hai. Mandi tak jaane me kharcha + fasal kharab hoti hai.

## Solution
Ek simple website jahan kisan seedha photo + daam daal ke apna product bech sake. Grahak seedha kisan se kharide.

## Features
- ✅ Photo Upload - Kisan phone se photo daal sakta hai
- ✅ Add / Edit / Delete Product
- ✅ Search + Filter + Sort
- ✅ Cart - Add / Remove / Quantity + / -
- ✅ WhatsApp Order + COD Order
- ✅ Dark / Light Mode Switch
- ✅ Hindi / English Friendly UI

## Tech Stack
HTML + CSS + JavaScript | LocalStorage
